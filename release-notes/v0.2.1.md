# BMray 0.2.1 — подписки

- Показывает объявление из `announce` и расход / лимит из `subscription-userinfo`.
- Показывает время последнего обновления и интервал из `profile-update-interval`.
- Автоматически обновляет просроченные подписки при открытом приложении и после следующего запуска; повторяет неудачную попытку через 15 минут.
- Позволяет закреплять подписки и менять их порядок внутри закреплённой и обычной групп. Порядок сохраняется.

APK подписан временным тестовым ключом. Перед удалением старой сборки сохраните ссылку подписки.
