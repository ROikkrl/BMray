## BMray 0.3.2

- У АвтоБС показывается протокол, транспорт и защита исходного локального хоста.
- Журнал подключения и запросы подписки доступны в разделе «Проверка соединения»; выбор способа пинга оформлен отдельными карточками.
- Обновление подписки отменяет выполняющийся пинг.
- На Android добавлен выбор приложений для VPN: весь трафик, только выбранные приложения или обход выбранных; системные приложения можно скрыть.
- Добавлены язык интерфейса (системный, русский, английский) и темы оформления, включая собственные темы из JSON Happ.
- Android APK и AAB теперь собираются с одним постоянным ключом из GitHub Actions Secrets. Для первой сборки владелец репозитория должен добавить четыре секрета подписи по инструкции в README.

Установленные прежде тестовые APK подписывались случайным ключом. Переход на постоянный ключ может потребовать однократной переустановки.
