## BMray 0.3.3

- Если вместо подписки сервер возвращает HTML, приложение один раз повторяет запрос с совместимым User-Agent и заголовком Accept для JSON. Пользовательский User-Agent, начинающийся с Happ, сохраняется без повторной подмены.
- В журнале запросов HTML-ответы помечаются как страница, проверка браузера, форма входа или перенаправление без сохранения содержимого страницы. Для сетевых ошибок указан этап запроса.
- Если повторный запрос тоже не содержит серверов, подписка не заменяется пустым ответом.
