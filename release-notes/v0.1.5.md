# BMray 0.1.5 — тестовая сборка Android

- Ссылки VLESS XHTTP сохраняются в списке серверов с явной пометкой о том, что этот транспорт требует ядро Xray. Подключение через них в текущем sing-box клиенте недоступно.
- Клиентские Xray JSON профили с VLESS gRPC REALITY конвертируются в конфигурацию sing-box.
- Исправлены декодирование названия подписки из Base64 и проверка Proxy GET по нескольким адресам (из версии 0.1.4).

APK и AAB собраны после тестов импорта, проверки конфигурации sing-box и REALITY соединения с тестовым Xray сервером. Реальные серверы пользователя не использовались.

**Установка:** каждый тестовый APK подписан одноразовым ключом. Для перехода с предыдущей тестовой сборки может потребоваться удалить её. Сохраните ссылку подписки до удаления: данные приложения будут удалены.
