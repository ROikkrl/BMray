# BMray 0.1.6 — тестовая сборка Android

- Добавлена работа VLESS XHTTP с TLS и REALITY через Xray 26.9.9 для Android arm64 и x86_64.
- Сохраняются `path`, `host`, `mode` и `extra` из ссылок и Xray JSON. Это необходимо для профилей с нестандартным XHTTP.
- Proxy GET для XHTTP проверяет соединение через тот же Xray. Обычные серверы продолжают работать через sing-box.
- Весь трафик остальных приложений идёт через системный VPN. Само приложение исключается из VPN при XHTTP, чтобы соединение Xray с сервером не зацикливалось.

APK подписан временным тестовым ключом. Перед удалением предыдущей тестовой версии сохраните ссылку на подписку: удаление приложения удалит её данные. Проверка реального сервера возможна только на устройстве с действующей подпиской.
