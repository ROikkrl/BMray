# BMray 0.1.8 — тестовая сборка Android

- Названия серверов, сведения о транспорте и ошибки в списке занимают одну строку и обрезаются многоточием. Текст задержки стал компактнее.
- Выбранный сервер подсвечен цветом и рамкой; кнопка подключения закреплена снизу и доступна при прокрутке списка.
- Добавлена вкладка «Настройки» с разделами «Пинг», «Информация», «Логи». Для Proxy GET, TCP и ICMP показано объяснение проверки; информация содержит версии приложения, Xray и sing-box, сведения о системе.

APK подписан временным тестовым ключом. Перед удалением старой сборки сохраните ссылку подписки.
