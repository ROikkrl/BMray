# BMray 0.2.2 — автовыбор и идентификатор подписки

- Нулевой лимит трафика теперь показывается как ∞.
- При неудачном импорте или ручном обновлении HTTPS-подписки показывается сообщение о недоступности сервера и возможных белых списках.
- Запросы подписки отправляют постоянный HWID, Cookie BMray и User-Agent BMray. В настройках можно изменить HWID и User-Agent.
- Последний выбранный сервер сохраняется между запусками приложения.
- Xray JSON с подготовленными Remnawave outbound'ами, `balancers` и `burstObservatory` получает отдельный профиль автовыбора. Подключение и Proxy GET используют исходные outbound'ы и балансировщик Xray.

Директива `injectHosts` выполняется на панели Remnawave. Для автовыбора импортируйте выданную подписку с подставленными серверами, а не сырой шаблон без outbound'ов.

APK подписан временным тестовым ключом. Перед удалением предыдущей сборки сохраните ссылки подписок.
