# BMray 0.1.7 — тестовая сборка Android

- Под названием сервера теперь отображаются протокол, транспорт и защита: например, `VLESS / XHTTP / REALITY`.
- Клиентские Xray JSON с Hysteria версии 2 импортируются и запускаются через Xray 26.9.9 на Android. Ссылки `hy2://` продолжают обслуживаться sing-box.
- Логотип в заголовке и иконки Android/iOS заменены на изображение, предоставленное владельцем проекта.

APK подписан временным тестовым ключом. Перед удалением старой сборки сохраните ссылку подписки.
