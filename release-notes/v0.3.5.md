## BMray 0.3.5

- Если подписка возвращает HTML-страницу вместо конфигурации, однократный повторный запрос использует точно `Happ/4.4.1/Android/17891107313301967618` в заголовке User-Agent. Обычные запросы сохраняют выбранный пользователем User-Agent.
- Повторный запрос для Base64-подписок с локальными адресами сохраняет прежнее поведение. Ответ без серверов не заменяет содержимое подписки.
