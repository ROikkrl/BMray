# BMray 0.3.9

- Раздельное туннелирование по доменам, IP/CIDR и странам GeoIP с именованными профилями и выбором маршрута по умолчанию. Настройки приложений доступны из этого же раздела.
- Ручная повторная загрузка GeoIP для активного профиля. Скачанные файлы сохраняются на устройстве и используются при следующем подключении.
- Ссылки `bmray://` на Android и iOS: открытие/закрытие приложения, подключение/отключение/переключение VPN, импорт URL подписки и конфигурации в Base64URL, добавление профиля маршрутизации в Base64URL JSON.
- Перед изменениями от внешней ссылки приложение показывает подтверждение. Импорт подписки принимает только HTTPS.

Формат профиля маршрутизации:

```json
{
  "name": "Мой профиль",
  "defaultRoute": "proxy",
  "directDomains": ["example.ru"],
  "proxyDomains": ["example.com"],
  "directIp": ["192.0.2.0/24"],
  "proxyIp": ["203.0.113.0/24"],
  "directGeoip": ["ru"],
  "proxyGeoip": ["us"]
}
```

Примеры ссылок:

```text
bmray://vpn/on
bmray://vpn/off
bmray://vpn/toggle
bmray://app/open
bmray://app/close
bmray://import/url?url=https%3A%2F%2Fexample.com%2Fsubscription
bmray://import/base64?data=<Base64URL UTF-8 contents>
bmray://routing/add?data=<Base64URL UTF-8 JSON above>
```

Домены в правилах совпадают с поддоменами. IP-правила требуют корректный CIDR, страны — двухбуквенный код ISO. При выборе профиля во время соединения VPN переподключается.
